# Tech PRD — 수식단순화 (Formula Simplification) v0.1

작성일: 2026-10-12
대상 플랫폼: iOS 27 (iPhone 전용, iPhone 16 시뮬레이터로 검증)
기술 스택: SwiftUI 중심, Swift Concurrency(async/await), Vision, SwiftData, Combine 허용

---

## 1. 배경과 비전

수만 개의 선분·곡선을 정의하는 수식만으로 얼굴, 동물, 패턴 같은 구체적인 그림을 그려내는 수학적 기법이 있다. 수식단순화(Formula Simplification)는 이 아이디어를 양방향으로 구현한 iPhone 앱이다.

1. **그리기 (수식 → 그림)**: 사용자가 매개변수 `t`와 레이어 인덱스 `k`에 대한 수식 `x(t, k)`, `y(t, k)`를 입력하면, 앱은 `k`에 대해 수백~수천 번 반복해 곡선/선분을 겹쳐 그린다. 각 수식이 거대한 그림 하나를 이룬다.
2. **변환 (그림 → 수식)**: 사용자가 사진을 가져오면, 앱은 Vision으로 윤곽을 추출하고 이산 푸리에 변환(DFT)으로 그 윤곽을 근사하는 실제 삼각함수 급수 `x(t) = Σ rₖ·cos(kt+φₖ)`를 계산해 보여준다. 항의 개수를 조절하면 그림이 더 단순해지거나 원본에 가까워진다.

두 방향 모두 "눈에 보이는 수식이 눈에 보이는 그림이 된다"는 핵심 체험을 공유한다.

## 2. 목표 / 비목표

### 목표 (v0.1)
- G1. 프리셋 또는 직접 입력한 수식을 0.5초 디바운스 후 Canvas에 즉시 그린다.
- G2. 수식 문자열을 안전하게 파싱·평가하는 자체 수식 엔진을 제공한다 (외부 코드 실행 없음).
- G3. 사진 1장에서 실제 동작하는 푸리에 급수 근사 수식을 생성하고, 항 개수를 1~200개 사이에서 조절할 수 있다.
- G4. 그리기·변환 결과를 기기에 저장하고 갤러리에서 다시 불러올 수 있다 (SwiftData).
- G5. iPhone 16 시뮬레이터(iOS 27)에서 네 개 탭(그리기/변환/갤러리/설정)이 모두 정상 동작한다.

### 비목표 (v0.1에서 제외)
- 임의 Swift/Python 코드 실행 (보안·App Store 정책상 자체 DSL만 사용).
- 아이패드/Mac/비전OS 레이아웃 (iPhone 전용).
- 동영상·3D 변환, 클라우드 동기화·공유.
- 실시간 카메라 스트림 윤곽 추출 (정지 사진만).

## 3. 사용자 시나리오

1. **그리기**: 앱을 열면 `그리기` 탭에 하트 곡선 프리셋이 그려져 있다. 수식 패널에서 `x(t,k)`를 수정하면 디바운스 후 캔버스가 다시 그려진다. 프리셋 메뉴에서 "나선 다발", "장미 곡선" 등으로 바꿔볼 수 있다. 완성한 그림은 사진 앱에 저장하거나 갤러리에 보관한다.
2. **변환**: `변환` 탭에서 사진 보관함의 사진을 선택한다. 앱이 윤곽을 찾아 즉시 하나의 선으로 다시 그린다. "항 개수" 슬라이더를 올리면 원본과 거의 같아지고, 내리면 추상적인 곡선이 된다. 아래 수식 패널에 실제 계산된 계수가 수학 표기로 표시된다. 결과를 갤러리에 저장한다.
3. **갤러리**: 저장한 그리기/변환 결과를 썸네일 그리드로 보고, 탭하면 해당 모드로 다시 열어 이어서 편집한다.
4. **설정**: 선 색상·굵기·배경·색상 순환(그려지는 순서에 따라 색이 바뀌는 효과) 등 렌더링 옵션을 조절한다.

## 4. 기능 요구사항

### FR-1 수식 엔진 (MathEngine)
- 렉서/파서/평가기로 구성된 자체 수식 언어. 트리 워킹 인터프리터로 안전하게 실행한다 (임의 코드 실행 아님).
- 지원 연산자: `+ - * / ^`(거듭제곱) 및 단항 `-`, 괄호.
- 지원 함수: `sin cos tan asin acos atan atan2 sqrt abs exp log min max floor ceil round`.
- 지원 변수: `t`(매개변수, 보통 0~2π), `k`(레이어 인덱스), `n`(총 레이어 수).
- 지원 상수: `pi`, `e`.
- 평가 한도: 레이어 최대 4,000개, 레이어당 샘플 최대 400개 (초과 시 자동 클램프), 평가 실패 시 줄·열과 함께 진단 표시.

### FR-2 레이어드 수식 모델 (LayeredFormula)
- 하나의 "작품"은 `x(t,k)`, `y(t,k)` 두 식, `t` 범위, `k` 범위(레이어 수), 색상 규칙(단색/색상 순환)으로 구성된다.
- `k`를 고정하고 `t`를 스캔하며 하나의 폴리라인을 그리고, 이를 `k`마다 반복해 겹쳐 그린다 — "수천 개 선으로 이루어진 그림" 기법.
- 프리셋 10종 이상 내장 (하트, 장미 곡선, 리사주, 나비, 스피로그래프, 나선 다발, 원형 다발 등), 각 프리셋에 수식 요약 텍스트 포함.

### FR-3 그리기 뷰 (DrawView)
- 상단 수식 편집기(모노스페이스) + 프리셋 메뉴, 중앙 `Canvas` 실시간 미리보기, 하단 수식 표기 패널(입력한 식을 π, 위·아래 첨자 등 읽기 쉬운 수학 표기로 변환해 보여줌).
- 450ms 디바운스로 재평가 후 다시 그림, 평가 오류 시 마지막 성공 결과 유지 + 오류 배너.
- 결과를 PNG로 사진 앱에 저장.

### FR-4 변환 파이프라인 (Fourier)
- `PhotosPicker`로 사진 선택 → `VNDetectContoursRequest`로 윤곽 추출 → 가장 긴 윤곽을 등간격 N점으로 리샘플링 → 복소수 좌표 `z(t) = x(t) + i·y(t))`에 이산 푸리에 변환(DFT) 적용 → 진폭이 큰 상위 K개 항만 남겨 `x(t) = Σ rₖcos(kt+φₖ)`, `y(t) = Σ rₖsin(kt+φₖ)` 형태의 실제 LayeredFormula로 변환.
- 항 개수(K) 슬라이더(1~200)로 근사 정밀도를 실시간 조절, 같은 Canvas 렌더러로 원본 윤곽과 겹쳐보기.
- 생성된 수식을 수학 표기로 패널에 표시 (상위 8개 항까지 나열 + "외 N개 항").

### FR-5 갤러리 & 영속성
- SwiftData 모델 `SavedArtwork`(종류: 그리기/변환, 수식 데이터, 썸네일, 생성일).
- 그리드 뷰, 탭하여 원래 모드로 열기, 스와이프 삭제.

### FR-6 설정
- 선 색상(단색 Picker) / 색상 순환 토글(레이어 진행에 따라 Hue 회전) / 선 굵기 슬라이더 / 배경(흰/검정) / 라이선스·앱 정보.

## 5. 비기능 요구사항
- 레이어 4,000개 × 샘플 400개(최대 160만 점) 상황에서도 UI가 멈추지 않도록 평가는 `Task`로 백그라운드에서 수행하고 `Canvas`에는 완성된 `Path` 배열만 전달한다.
- 모든 상태는 `@Observable` 모델로 관리하고 Combine은 디바운스 등 보조적 용도로만 허용한다.
- 접근성: Dynamic Type 대응, 버튼에 `accessibilityLabel` 제공.
